# HAVERA Home

Premium home-finishing storefront for bathrooms, kitchens, tile, flooring, paint, lighting, mirrors and renovation essentials.

## Features
- Professional showroom-inspired design
- Local image assets included in the package (no external image dependency for the core visual assets)
- 187 products across 12+ home categories
- Search, category filters and sorting
- Product detail pages
- Shopping cart and wishlist using localStorage
- Collections, deals, new arrivals, support, shipping, returns and FAQ pages
- Responsive layout for desktop and mobile
- GitHub Pages ready
